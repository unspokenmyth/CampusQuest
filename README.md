# University-Themed 2D Platformer

A **2D platformer** built in **Unity**, inspired by Super Mario, featuring custom mechanics and a university-themed environment.

## 🎮 Features
- Classic platformer gameplay with smooth jumping and movement.
- Blocks that release coins when hit, with appropriate sound effects.
- Enemy interactions with stomp mechanics.
- Optimized sound system:
  - "Bump" sound for regular block hits.
  - "Coin" sound only when a block contains a coin.
  - Jump and enemy defeat sound effects.

## 🕹️ Controls
- **Arrow Keys / A & D** - Move Left/Right
- **Spacebar** - Jump
- **Shift** - Sprint

## 🔧 Installation
1. **Clone the repository**
   
3. **Open in Unity**
   - Ensure you have Unity installed (preferably the version used for this project).
   - Open Unity Hub and add the cloned project.
4. **Play & Modify**
   - Press `Play` in Unity to test the game.
   - Modify assets, tweak mechanics, or expand levels!
